# Applied Agentic AI Experiments 🤖

A collection of hands-on experiments exploring **LLMs, RAG, Agents, Tool Use, and Multi-Agent Systems**.

## Experiments

1. **Text-to-SQL Workflow**
   Converts natural-language questions into SQL queries.

2. **RAG-Based Question Answering**
   Implements indexing, retrieval, and response generation.

3. **Prompt Chaining for Summarization**
   Uses multi-step prompts to extract, organize, summarize, and refine information.

4. **SQL Agent with Tool Use**
   Builds a ReAct-style agent that interacts with a SQLite database using tools.



## Technologies

* Python
* Ollama
* SQLite / SQL
* RAG
* LLMs
* ReAct Agents
* Prompt Engineering

**Goal:** Learn and implement practical **Agentic AI workflows** through hands-on experiments.
